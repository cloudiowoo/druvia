# 单租户模式 UI 优化设计文档

## 概述

Phase 5 P2 实现了单租户模式开关（`NEXT_PUBLIC_MULTI_TENANT_ENABLED=false`），但前端界面仍保留多租户视角的元素。本设计优化单租户模式下的用户体验，移除冗余概念。

**创建日期**: 2026-03-08
**状态**: 已审核

---

## 设计目标

- 移除多租户相关的 UI 元素和术语
- 简化导航结构
- 提供完整的首页体验
- 保持多租户模式切换能力

---

## 1. 首页重构

### 变更概述

| 页面 | 当前 | 调整后 |
|------|------|--------|
| `/dashboard` | 全局统计仪表板 | 重定向到 `/t/default` |
| `/t/default` | 租户概览（项目列表 + 租户属性卡片） | 完整首页 |

### `/t/default` 新布局

```
┌─────────────────────────────────────────────────────────┐
│  Druvia                                                 │
│  欢迎回来，{username}                                    │
├─────────────────────────────────────────────────────────┤
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐       │
│  │ 项目数   │ │ 用户数   │ │ 备份数   │ │ 存储使用 │       │
│  │   3     │ │   12    │ │   5     │ │ 2.1 GB  │       │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘       │
├─────────────────────────────────────────────────────────┤
│  我的项目                              [+ 创建项目]      │
│  ┌─────────────────────────────────────────────────┐   │
│  │ myapp        活跃    →                          │   │
│  │ blog         活跃    →                          │   │
│  │ api-service  活跃    →                          │   │
│  └─────────────────────────────────────────────────┘   │
├───────────────────────────┬─────────────────────────────┤
│  最近活动                  │  系统状态                    │
│  • 创建项目 myapp          │  API 服务    ● 正常         │
│  • 用户登录                │  数据库      ● 正常         │
│  • 创建备份                │  Hasura      ● 正常         │
│                           │  Redis       ● 正常         │
└───────────────────────────┴─────────────────────────────┘
```

### 移除的元素

- 租户属性卡片（别名、套餐、状态）
- 标题从「{租户名}」改为「Druvia」
- 副标题从「租户概览」改为「欢迎回来，{username}」

### 新增的元素

- 统计卡片（项目数、用户数、备份数、存储使用）
- 最近活动列表
- 系统状态面板

## 2. 导航调整

### Sidebar 全局导航

| 位置 | 当前（单租户模式） | 调整后 |
|------|-------------------|--------|
| 第一项 | 仪表板 → `/t/default` | 首页 → `/t/default` |
| 其他 | 用户管理、备份管理、设置 | 保持不变 |

```
┌──────────────────────┐
│  Druvia              │

├──────────────────────┤

├──────────────────────┤
│  admin@druvia.local  │
│  [退出]              │
└──────────────────────┘
```

## 3. 设置页简化

### 平台设置配置项

| 配置项 | 当前 | 调整后 |
|--------|------|--------|
| 默认套餐 | 显示 | 隐藏 |
| 默认存储限制 | 显示 | 保留（改名为「存储限制」） |
| 默认项目数限制 | 显示 | 隐藏 |
| 默认用户数限制 | 显示 | 隐藏 |
| 备份保留天数 | 显示 | 保留 |
| 最大备份数量 | 显示 | 保留 |

### 标题变更

- 卡片标题：「平台设置」→「系统设置」

## 4. 路由重定向

### 路由行为

| 路径 | 单租户模式行为 |
|------|---------------|
| `/` | 重定向到 `/t/default` |
| `/dashboard` | 重定向到 `/t/default` |
| `/tenants` | 重定向到 `/t/default` |
| `/tenants/new` | 重定向到 `/t/default` |
| `/t/default` | 显示完整首页 |
| `/t/default/projects` | 保留（项目列表页） |
| `/t/default/p/[projectId]/*` | 保留（项目详情页） |

### 实现方式

在 `middleware.ts` 中添加单租户模式重定向逻辑。
